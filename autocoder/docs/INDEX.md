## Key Concepts

### Five Fixes
1. **Task Status Tracking** - TASKS.md with checkbox format
2. **Lock File Guard** - .autocoder.lock prevents concurrent runs
3. **Cron-Only Execution** - Time-gated 1:00 AM - 4:45 AM
4. **Run Log** - NIGHTLY_LOG.md with detailed entries
5. **Run State** - RUN_STATE.json for quick status

### Three Skills
1. **spec-creation** - Creates specifications (one-time)
2. **spec-coding** - Executes one task per invocation
3. **autocoder** - Orchestrates overnight execution

### Three Data Files
1. **TASKS.md** - Task queue with status
2. **NIGHTLY_LOG.md** - Execution log
3. **RUN_STATE.json** - Current state
